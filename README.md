# Text-to-Image-Search-Engine
An end-to-end multimodal search engine built with CLIP and FAISS that enables sub-10ms text-to-image semantic retrieval across 10,000+ images

Skill/Tech Stack:
1) Languages & Frameworks: Python, PyTorch, Sentence-Transformers
2) AI / DL Models: OpenAI CLIP (Vision Transformer - ViT-B/32), Multimodal Embeddings
3) Vector DB & Search: Meta FAISS (HNSW, Flat Indexing), Cosine Similarity
4) Web & DevOps: Streamlit, Docker, Hugging Face Spaces, Git/GitHub
